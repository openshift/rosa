# ROSA Verification Gates

Use this skill when preparing to commit or open a PR, or verifying code,
command, documentation, or generated-file changes.

1. Read [AGENTS.md](../../../AGENTS.md) and its
   [testing guidelines](../../../guidelines/testing-guidelines.md).
2. Classify the changed files and apply the corresponding structure,
   generation, and test expectations from that guide.
3. Use [CONTRIBUTING.md](../../../CONTRIBUTING.md) for exact check commands
   and hook behavior. Run the checks relevant to the change.
4. Complete the [PR template](../../../.github/pull_request_template.md)
   using the checks actually run, plus manual validation and risk notes.
